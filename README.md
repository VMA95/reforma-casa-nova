# Reforma Casa Nova

App para organizar as demandas da reforma, por cômodo, com fotos.

---

## Como subir no GitHub Pages

### 1. Criar o repositório

1. Acesse [github.com](https://github.com) e entre na sua conta (VMA95)
2. Clique no botão **"New"** (ou **"+"** no canto superior direito → "New repository")
3. Em **Repository name** coloque: `reforma-casa-nova`
4. Deixe como **Public**
5. Clique em **Create repository**

---

### 2. Subir os arquivos

Após criar o repositório, na página que aparecer clique em **"uploading an existing file"**.

Arraste ou selecione os 3 arquivos:
- `index.html`
- `style.css`
- `app.js`

Clique em **"Commit changes"**.

---

### 3. Ativar o GitHub Pages

1. No repositório, clique em **Settings** (aba no topo)
2. No menu da esquerda clique em **Pages**
3. Em **Source** selecione **Deploy from a branch**
4. Em **Branch** selecione **main** e pasta **/ (root)**
5. Clique em **Save**

Aguarde 1-2 minutos. O link do app vai aparecer assim:

```
https://VMA95.github.io/reforma-casa-nova/
```

---

### 4. Compartilhar

Envie esse link para sua esposa e para a arquiteta. Funciona em qualquer celular ou computador, sem instalar nada.

---

## Observações

- Os dados ficam salvos no navegador de cada pessoa (localStorage)
- As fotos ficam salvas no Cloudinary (cloud name: dvloudsbh)
- Se limpar o cache do navegador, os dados de texto são apagados (as fotos no Cloudinary permanecem)
